# LLM Usage Report – Week 3

We used large language models (LLMs) in the following tasks:

1. **Acceptance criteria** – to generate initial drafts of AC for each PBI.

2. **Documentation** – to generate templates for files in "docs" and "week3".

3. **Transcription and translation** – the customer review meeting recording was transcribed using TurboScribe and then translated from Russian to English for the final transcript.

4. **Testing** – LLMs were used as a reference to understand testing approaches and best practices. However, all test code was written manually by the team.

All generated content was reviewed, corrected, and adapted by the team. No confidential or real credentials were shared with LLMs.
