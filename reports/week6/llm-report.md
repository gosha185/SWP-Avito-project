# LLM Usage Report – Week 6

We used large language models (LLMs) in the following tasks during Week 6:

## 1. Documentation

Used ChatGPT to draft and refine the following documentation:

- `README.md` — as the main public repository entry point
- `AGENTS.md` — agent-facing guide for coding AI tools
- DoR and DoD checklists for GitHub issue templates

All drafts were reviewed, corrected, and adapted by the team to match the actual project state.

## 2. Meeting Transcription

Used AI-based transcription tools (TurboScribe) to transcribe the Week 6 Sprint Review meeting with the customer. The raw transcript was then cleaned, formatted, and sanitized (removing PII) using ChatGPT before being committed to the repository.

## 3. Report Templates

Used ChatGPT to generate initial templates for:
- `reports/week6/reflection.md`
- `reports/week6/retrospective.md`
- `reports/week6/llm-report.md`
- `reports/week6/sprint-review-summary.md`

All generated content was reviewed, corrected, and adapted by the team.

## Notes

- No confidential or real credentials were shared with LLMs.
- All AI-generated content was reviewed, verified, and adapted by the team.
- LLMs were used as productivity tools to accelerate drafting and structuring, not as a replacement for team decision-making.
