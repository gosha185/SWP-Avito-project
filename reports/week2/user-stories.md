User Stories

US-01: Admin view total points in circulation
Requirement status: Active  
MoSCoW priority: Could Have
As an admin,  
I want to receive the number of points,  
so that I can track the quantity in circulation.
Notes and constraints:  

US-02: Bonuses not lost during failures
Requirement status: Active  
MoSCoW priority: Should Have
As an admin,  
I want to prevent duplicate bonus accruals when a request is retried due to a temporary failure,  
so that users are not credited multiple times for the same action.

US-03: Bonuses with different lifespans
Requirement status: Active  
MoSCoW priority: Should Have
As an admin,  
I want bonuses to have different lifespans,  
so that I can make promotions and time‑limited offers.

US-04: Warning about exceeding point limit
Requirement status: Active  
MoSCoW priority: Should Have
As an Avito worker,  
I want a warning about exceeding the point limit,  
so that we can detect cheating and prevent abuse.

US-05: View points that will expire soon
Requirement status: Active  
MoSCoW priority: Could Have
As a user,  
I want to see bonus points that will expire soon,  
so that I can use these points before they expire.

US-06: View points held for a concrete order
Requirement status: Active  
MoSCoW priority: Must Have
As a user,  
I want to see how many points are held for a concrete order,  
so that I can analyse the number of points awarded.

US-07: View current available point balance
Requirement status: Active  
MoSCoW priority: Must Have
As a user,  
I want to see my current available bonus balance,  
so that I know how many points I can spend now.

US-08: Admin view transaction history
Requirement status: Active  
MoSCoW priority: Should Have
As an admin,  
I want to see a complete ledger of all point transactions,  
so that I can audit and reconcile balances.

US-09: Service outage pop-up notification
Requirement status: Active  
MoSCoW priority: Should Have
As a user,  
I want to see a pop-up bar in the application about service problems,  
so that I know not to use the app during that time.

US-10: Bonuses not lost during failures (removed version)

Requirement status: Removed  
Previous MoSCoW priority: Should Have

As an admin,  
I want bonuses not to be lost during failures,  
so that we maintain the trust of users.

Reason: The requirement was too broad and not verifiable. Replaced with US-02.

Initial proposed MVP v1 scope

From the active Must Have stories, the following are proposed for MVP v1:

- US-06 – View points held for a concrete order  
- US-07 – View current available point balance
